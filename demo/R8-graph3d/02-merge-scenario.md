# R8-02 左右对比与同名节点合并

> **验证点**：左右各选一个图元素后，可以并排看两张图；点「合并左右」后，
> **只有跨图的同名节点**会合并，两个图通过共享节点连成一个整体。
>
> **怎么验**：
> 1. 右键本文件 → **3D 可视化浏览**；
> 2. 左下拉选「登录流程 v1（左） · 流程图」，右下拉选「登录流程 v2（右） · 流程图」；
> 3. 两侧都选中后出现分隔条，左右各占 50%；拖动分隔条可在 15%–85% 之间调整，双击复位；
> 4. 点「合并左右」，统计应为 **4 节点 / 4 边 / 已合并 3 个同名节点**；
> 5. 按 `Esc` 或点「取消合并」回到左右分栏；
> 6. 再把左右换成「无同名节点 A / B」并合并，统计应为 **4 节点 / 2 边 / 未合并节点**（两侧保持独立）；
7. 合并状态下把「布局」切到 **互斥 · 紧凑分层**（或 **互斥 · 3D 力导向**）：公共链 `登录页 → 鉴权服务 → 用户库` 留在左边，右侧独有的 `风控服务` 被推到最右，状态行显示「左核「登录页」· 右核「风控服务」」。

## 自己造一个对比场景

1. 复制任意两个图元素到新的 Markdown 文件；
2. 让它们共享至少一个**节点标签**（节点 id 可以不同，合并看的是显示标签）；
3. 右键新文件打开 3D，左右各选一个图，点「合并左右」。

合并规则摘要：

- **只跨左右两个元素合并**；同一张图内部的同名节点不合并；
- 名称先 `trim`、连续空白压成一个空格、去掉首尾引号 / 反引号、再转小写比较；
- 右侧未匹配节点用 `r:` 前缀重新分配 id，右侧分组 id 同样重映射；
- 边按 `source + target + label + dashed` 去重，其余全部保留。
