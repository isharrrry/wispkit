# R8-05 条目注释与数据流名称

> **验证点**：
> 1. 工具栏新增「显示数据流名称」复选框：勾选时连线中点显示边名称，取消勾选立即隐藏；
> 2. ASCII 树的行尾注释（`# …` / `// …`）、整行注释、折行注释都能识别成**节点注释**，
>    不会混进节点标签；
> 3. Mermaid 的 `%%` 整行注释与行尾注释会挂到对应节点；
> 4. 3D 里把鼠标悬停在带注释节点的气泡区域，会出现 tooltip 临时显示注释。

## 1. ASCII 树：行尾 / 整行 / 折行注释

```text
Wispkit 源码
├── src                            # 扩展宿主 TypeScript
│   ├── extension.ts               # 注册命令与视图
│   ├── graph3d                    # 3D 解析与布局（纯逻辑）
│   │   # graph3d 下的模块都不 import vscode，可以在 mocha 里直接跑
│   │   └── ascii.ts               # ASCII 树解析，含注释识别
│   └── test                       // 与 src 一一对应
├── media                          # webview 前端资源
│   └── graph3d.js                 // 悬停 tooltip 与数据流名称开关
└── C# 示例                        # 标签里的 # 不算注释分隔符
```

预期：

| 节点 | 悬停气泡时的 tooltip |
|---|---|
| `src` | `扩展宿主 TypeScript` |
| `extension.ts` | `注册命令与视图` |
| `graph3d` | `3D 解析与布局（纯逻辑）` + 下一行整行注释（`graph3d 下的模块都不 import vscode…`） |
| `ascii.ts` | `ASCII 树解析，含注释识别` |
| `graph3d.js` | `悬停 tooltip 与数据流名称开关` |
| `C# 示例` | `标签里的 # 不算注释分隔符` |

`C# 示例` 节点标签是 `C# 示例`——`C#` 里的 `#` 前面没有空白，不会被当成注释起点。

## 2. Mermaid：`%%` 注释 + 边名称

```mermaid
flowchart TD
  %% 登录流程：整行注释挂到下一行新建的节点上
  A[登录页] -->|提交账号密码| B[校验服务]
  B -->|校验通过| C[首页]
  B -->|校验失败| D[错误提示] %% 行尾注释属于本行新建的 D
  %% 帮助中心
  E[帮助] -->|查看指引| A
```

预期：

- 左侧选中这张流程图后，连线中点出现 `提交账号密码`、`校验通过`、`校验失败`、`查看指引`；
- 取消勾选「显示数据流名称」，这些文字立即消失，再勾选恢复；
- 悬停 `登录页` / `校验服务` 气泡：tooltip 为 `登录流程：整行注释挂到下一行新建的节点上`；
- 悬停 `错误提示` 气泡：tooltip 为 `行尾注释属于本行新建的 D`；
- 悬停 `帮助` 气泡：tooltip 为 `帮助中心`。

> 说明：注释只在节点有内容时出现；没有注释的节点不会弹 tooltip。
