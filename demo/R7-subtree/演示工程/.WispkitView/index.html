演示工程 · Wispkit 展示页

这个页面是被 .WispkitView/Wispkit.json 里的配置打开的，不是手动双击的。

它是怎么被打开的

在资源管理器里右键「演示工程」这个文件夹 → 点 展示（$(open-preview) 图标）→ Wispkit 找到 .WispkitView/Wispkit.json → 按配置里的 entry + openWith 打开本页。 

{
  "title": "R7 子树浏览演示",
  "entry": ".WispkitView/index.html",
  "openWith": "wispkit.html"
}

如果你看到这一页

✓ 说明「展示」图标、配置查找、entry 解析、viewType 打开这四步全通了。

步骤 对应实现
找到配置 先查 <文件夹>/.WispkitView/Wispkit.json，再查 <文件夹>/Wispkit.json
解析 entry 相对被点击的那个文件夹解析，且不允许跑到文件夹外面
打开 vscode.openWith(entry, openWith)，本页用的是 wispkit.html
