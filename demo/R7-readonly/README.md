# R7 只读模式演示数据

## 怎么验

1. 点 VS Code **状态栏右下角**的 `$(unlock) 可编辑` → 变成 `$(lock) 只读`。
2. 在本文件夹里打开 `big-sample.log`（约 1.5 MB / 20000 行）。
3. 预期：**不是**原生文本编辑器，而是「只读模式 · 只加载了前 800 行（文件共 …），未加载的部分不会渲染」的预览页，右下角有悬浮的「解锁编辑」按钮。
4. 点「解锁编辑」→ 这个文件改回 VS Code 原生编辑器打开，可以正常编辑；只读预览那个标签页会被关掉。
5. 再点一次状态栏开关 → 退出只读模式；之后打开任何文本文件都回到原生编辑器。

## 文件

| 文件 | 用途 |
|---|---|
| `big-sample.log` | 约 1.5 MB / 20000 行合成日志，用来体现"只加载文件头若干字节" |
| `notes.md` | 反例：Markdown **不受**只读模式影响（它走 Wispkit Markdown 视图），否则截断会让渲染结果残缺 |

## 相关配置

| Key | 默认 | 作用 |
|---|---|---|
| `wispkit.readonly.default` | `false` | 启动时是否进入全局只读模式 |
| `wispkit.readonly.previewBytes` | `65536` | 最多读进内存的字节数 |
| `wispkit.readonly.previewLines` | `800` | 最多显示的行数 |

## 想更直观地看到差异

把 `wispkit.readonly.previewLines` 改成 `20`，回到预览页（或重新打开该文件），横幅会显示"只加载了前 20 行"，正文也只剩 20 行。
