# R2-03 标题里的特殊字符

> **验证点**：标题文本被原样搬进目录；标题里的行内标记**不应**把 Markdown 语法符号漏进目录。
> **期望**：目录条目文字与下面每个标题的**可见文字**一致（不出现 `**`、`` ` ``、`$`、方括号等源字符）。

## 纯中文标题：配置文件加载顺序

中文标题要能正常显示，且点击后精确定位（中文 id 在 URL 片段里要能工作）。

## Title with English and Numbers 2026

英文标题。

## 带 `行内代码` 的标题

目录里应显示「带 行内代码 的标题」（没有反引号）。

## 带 **粗体** 与 *斜体* 的标题

目录里不应出现星号。

## 带 [链接](https://example.com) 的标题

目录里应显示「带 链接 的标题」，点击目录条目本身**不应**跳到 example.com（目录项是新建的 `<a href="#id">`，与标题里的链接无关）。

## 带公式 $E = mc^2$ 的标题

目录里应显示 KaTeX 渲染后的可见文字，或至少不出现 `$` 符号。

## 带 emoji 🚀 与符号 < > & " ' 的标题

HTML 特殊字符不能破坏目录结构（`&` 不应变成 `&amp;` 显示出来，`<` 不应把结构咬断）。
